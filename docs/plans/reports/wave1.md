## Decisions made within D1 to D6

- Preserved the exact runtime-independent session seam. Clippy's existing seven-argument threshold is locally allowed on the two functions that gained separate `app` and `sink` arguments, instead of introducing a generalized runtime object prohibited by the plan.
- Used rig's inner structured HTTP error display for structured 429 details. The real streaming path produces the plan's exact text and T-R15 asserts it byte for byte.
- Used `/tmp` only as the no-environment request-log fallback for direct live tests. Release invocations continue to use the explicit `KUKU_LIVE_REQUEST_LOG` path.
- Ordered verifier execution as T-L1, T-L3, T-L2. This makes the bound v21 partial-failure case deterministic: a failed T-L2 renewal skips both completed tests and finishes at cumulative `chat=4 models=2`.
- Kept the non-strict T-L2 structural assertion for compatible local models. qwen3.5:4b also passed the optional exact-text assertion when strict mode was enabled.
